## Description

Supper Club AI is an agent-readable cultural hosting workspace—not another AI dinner planner. In this demo, ChatGPT uses 28 page-native WebMCP tools to turn Toni Morrison's *Jazz* into one coordinated Harlem supper for eight.

The host and agent work inside the same visible, editable plan. ChatGPT creates the evening, reviews live provider receipts, searches for a gluten-free course, checks candidate prices at a selected Kroger location, changes only the chosen dish, and keeps the shopping list, prep timeline, recipe cards, wine, music, and cultural notes synchronized.

The demo also shows the safety boundary: Supper Club AI stops before consequential actions. The host must explicitly approve the final plan before WebMCP produces the downloadable kitchen packet.

### What the demo shows

- 28 tools registered directly by the webpage through WebMCP
- Dynamic recipe discovery with Spoonacular and Perplexity Agent API
- Wine discovery and pairing through GrapeMinds
- Soundtrack discovery with Perplexity and Apple Music verification
- Location-aware grocery estimates, package matching, promotions, and confidence through Kroger
- Visible provider receipts, fallbacks, warnings, and Agent Marginalia
- Shopping lists organized by dish and aisle
- Source-aware recipe cards and a downloadable kitchen packet
- Explicit host approval before finalization or export
