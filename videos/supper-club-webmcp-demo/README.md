# Supper Club AI WebMCP Demo Video

This directory contains the HyperFrames composition source, storyboard, narration script, captions, edit manifest, and upload metadata for the public hackathon demo.

The edit follows one complete WebMCP story: create a Toni Morrison *Jazz*-inspired plan, inspect provider receipts, replace and price one course, rebuild downstream planning materials, and require host approval before exporting the kitchen packet. The final motion-graphics chapter presents the retailer and independent-grocer opportunity.

Large local production assets are intentionally excluded from Git:

- raw screen recordings and local asset symlinks;
- generated narration WAV/MP3 files;
- HyperFrames caches and validation snapshots;
- the 130 MB rendered MP4.

The final video is distributed through YouTube, as required by the hackathon. Add its public URL to [`YOUTUBE_METADATA.md`](./YOUTUBE_METADATA.md) and the project README after upload.

The upload-ready YouTube and Devpost artwork remains under [`marketing/`](./marketing/).
