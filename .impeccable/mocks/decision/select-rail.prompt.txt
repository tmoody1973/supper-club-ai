Create a high-fidelity 16:10 desktop web application UI comp for “Supper Club AI,” an operating workspace for a Creative Host. Each frame contains tiny but legible course, recipe, music, and pairing information. A folded tape flag marks the selected “Main table” frame. Below the rail, a wide selected-scene editor occupies two-thirds of the screen with smoked sweet potato, black-eyed pea dish, climate note, allergy status, Apple Music cue, wine pairing, host note, and edit/confirm controls. The lower right is a live tool receipt area showing “Recipe matched,” “Playlist updated,” and “Shopping list reconciled.” Deferred recipes and tracks hang below the rail on visible pins as recoverable trims. Narrow left mast lists Theme, Menu, Wine, Music, Reading, Guests, Shopping, Prep.

One condensed grotesk size system with hierarchy expressed through cell spans, caps for labels, monospaced timecode. State is marks, not color: grease cross done, punched corner unavailable, tape band committed, folded flag current, hung pin deferred. Perforation pitch rules spacing and edges. Square corners, hairline rules, tactile grain. Keep food and hospitality prominent so the metaphor serves the product.
